# Anuj Munda — AI & Design Technology Portfolio

Static responsive portfolio tailored to Ather Energy's AI Generalist, Design internship.

## Publish publicly with GitHub Pages
1. Create a **Public** repository on GitHub named `portfolio`.
2. Upload `index.html` to the repository root and commit.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Once GitHub reports deployment, visit `https://Anujmunda.github.io/portfolio/` in an incognito/private window and verify it loads without signing in.
6. Submit the live Pages URL, **not** the repository URL. Public repository visibility and Pages deployment are separate checks.

No backend, credentials or dependencies required. Update project cards with direct repository/demo URLs when available. Proposed Ather workflow concepts are explicitly labeled as concepts, not completed projects.
